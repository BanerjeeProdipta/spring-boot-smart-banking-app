# Smart Banking App

A simulated retail-bank backend built with Spring Boot. See [PRD.md](PRD.md) for the full product requirements, architecture, and phased build plan.

## Status

Early build — see [milestones](../../milestones) and [issues](../../issues) for current progress.

## Build order

Phases are tracked as GitHub milestones (M1–M6), matching PRD section 11:

1. **M1** — Core monolith (accounts, deposits, withdrawals, transfers, history)
2. **M2** — Security and authentication
3. **M3** — Events, outbox, service split, fraud rules
4. **M4** — Resilience and observability
5. **M5** — Deployment and delivery
6. **M6** — Polish and optional Phase 6
